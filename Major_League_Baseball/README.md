# ⚾ MLB Data Analytics SQL Project

## Overview
This project explores historical player data from Major League Baseball (MLB) using advanced SQL querying techniques. As a Data Analyst Intern, the goal is to extract meaningful insights from decades of player and team data, focusing on trends, comparisons, and career patterns.

The dataset includes:
- Player demographics (height, weight)
- Schools attended
- Salaries
- Teams played for
- Career timelines

---

## Objectives

This project answers the following key analytical questions:

1. **Schools Analysis**
   - Which schools have produced the most MLB players?
   - Are certain schools consistently associated with high-performing players?

2. **Salary Insights**
   - How much do teams spend on player salaries over time?
   - Which teams have the highest payrolls historically?

3. **Career Exploration**
   - What does a typical MLB player career look like?
   - How long do players stay active in the league?

4. **Player Attribute Comparison**
   - How do player attributes (height, weight) vary across teams and eras?
   - Are there observable trends in physical characteristics over time?

---

##  Skills & Concepts Applied

- Advanced SQL querying
- Joins (INNER, LEFT, SELF)
- Aggregations (SUM, AVG, COUNT)
- Window functions
- Subqueries & Common Table Expressions (CTEs)
- Data filtering and transformation
- Time-series analysis

---

Key Insights
Certain schools consistently produce a high number of MLB players.
Team salary spending has significantly increased over time.
Player career lengths vary widely across the league.
Player physical attributes show subtle trends across different eras.
